# Release notes

## [1.2.0]

### Added

- Added `process-mitochondrial-bam` as the first submodule in the standalone BAM post-process module, with the `recruit` and `call` subcommands.
- Added an end-to-end mitochondrial read recovery workflow with a pinned `vg` binary and GRCh38 NuMT resources.
- Added unit tests for recruitment, GAF processing, coverage initialization, length normalization, and abundance estimation.

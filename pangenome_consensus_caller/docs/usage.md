# Usage

## Consensus correction

Corrects duplex consensus bases using a pangenome graph alignment.
Input: **Giraffe-aligned duplex BAM** → Output: **corrected BAM**.

```shell
pangenome_consensus_caller -b no_repeat.bed -t 16 < input.bam > output.bam
```

To run the Pan-Genome Consensus Caller, go to [Consensus correction](usage-pangenome-consensus-caller.md).

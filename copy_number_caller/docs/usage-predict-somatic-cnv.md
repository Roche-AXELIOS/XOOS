# Re-call somatic copy numbers

## How it works

The `predict-somatic-cnv` subcommand predicts copy numbers from the results of `tumor-normal-wgs` or `tumor-only-wgs` mode (log-ratios, b-allele fractions, and segments) using a user defined purity/ploidy solution.

This workflow applies the same logic internal to `tumor-normal-wgs` and `tumor-only-wgs` modes, but was made available as a dedicated subcommand if the user already has segments, log-ratios and a list of germline heterozygous variants, or if the user wishes to test other purity and ploidy combinations.

`predict-somatic-cnv` uses a likelihood model that takes the log-ratios, BAFs, observed segments, tumor purity, and tumor ploidy as input to predict the total and allele-specific copy numbers for each segment.
The tumor purity and the tumor ploidy must be known to run the likelihood model.

Expand the details below for the step-by-step design of this command.

<details>
<summary>Design details.</summary>

1. For each segment, calculate a log-ratio likelihood for each possible total copy number using the mean of the segment's log-ratio observations. This produces a vector with one value per total copy number.
2. Select the total copy number with the highest log-ratio likelihood.
3. If the segment has BAF observations, estimate its mirrored BAF peak from the allele-depth observations, then calculate a BAF likelihood for each possible minor copy number conditional on the selected total copy number. Select the minor copy number with the highest BAF likelihood.
4. Add the selected BAF likelihood to the selected log-ratio likelihood to obtain the segment's joint likelihood. The BAF likelihood does not change the selected total copy number. If the segment has no BAF observations, its joint likelihood is its log-ratio likelihood, and no minor copy number is assigned.

</details>

## Example command

{% hint style="warning" %}
If the input segments, log ratios, and BAFs were generated by `tumor-only-wgs`, include `--tumor-only`. This option is not inferred from the input files; it enables tumor-only germline/somatic segment classification and marks germline segments in the output VCF. Do not use it for `tumor-normal-wgs` inputs.
{% endhint %}

```bash
copy_number_caller predict-somatic-cnv \
        --segments <segments> \
        --log-ratios <log_ratios> \
        --bafs <bafs> \
        --reference /path/to/reference \
        --tumor-purity <FLOAT> \
        --tumor-ploidy <FLOAT> \
        --sex <male, female, or unknown> \
        --output-dir /path/to/output
```

This command calls somatic CNVs from the output files produced by `tumor-normal-wgs` or `tumor-only-wgs`.
It generates output files, including segment and VCF files, which are saved to `/path/to/output`.

For more details on available CLI options, see the [CLI options](#cli-options) section below.

## Input

The segments, log ratios, and BAF inputs can be produced by either the [`tumor-normal-wgs`](usage-tumor-normal-wgs.md) or [`tumor-only-wgs`](usage-tumor-only-wgs.md) subcommand. For inputs from `tumor-only-wgs`, use `--tumor-only` as described above.

| Input | Required | Notes |
|:---------|:-----------------------|:-----------------------|
| Segments | Yes | Segments file in [SEG](file-formats.md#segments) format (`--segments`), as output by `tumor-normal-wgs` or `tumor-only-wgs`. |
| Log ratios | Yes | Log ratios file in [log ratios](file-formats.md#log-ratios) BED format (`--log-ratios`), as output by `tumor-normal-wgs` or `tumor-only-wgs`. |
| BAFs | Yes | Tumor BAF values in [BAFs](file-formats.md#bafs) BED format (`--bafs`), as output by `tumor-normal-wgs` or `tumor-only-wgs`. |
| Reference FASTA | Yes | Indexed reference genome (`--reference`). |
| Tumor purity and ploidy | Yes | Known or experimental tumor purity and ploidy values (`--tumor-purity`, `--tumor-ploidy`). |
| Sex | Yes | Sex of the sample (`--sex`). |

## Output

Files are written to the current working directory by default.
The output folder can be specified with `--output-dir`.
A custom prefix (for example a sample ID) can be prepended to every output filename with `--output-prefix`; the prefix and the default name are joined with an underscore (for example, `--output-prefix TN` produces `TN_somatic_copy_number_callset.vcf.gz`). When `--output-prefix` is omitted, the default filenames below are used.
The output directory is created if it does not exist. If an output file already exists, the command exits with an error unless `--overwrite` is specified.

| Output | Description |
|:---------|:-----------------------|
| *somatic_copy_number_callset.seg*  | Copy number estimations for each segment along with their likelihoods in [SEG](file-formats.md#segments) format.          |
| *somatic_copy_number_callset.vcf.gz*  | Copy number estimations for each segment in [VCF](file-formats.md#vcf) format.          |
| *somatic_copy_number_callset.vcf.gz.tbi* | Tabix index for the compressed VCF. |

Notes:

- The sample ID in the output is parsed from the input segments file (`Id` column). If a sample ID is not found, it will be "sample" by default.
- When the sex is `unknown`, the caller skips copy-number likelihood calculations for allosome segments (chromosomes X and Y), because it cannot determine whether those segments are haploid or diploid.

## CLI options

This command also accepts the common `-h, --help`, `-v, --version`, and `-l, --log-level` (`debug`, `info`, `warn`, `error`; default `info`) options.
Parameters in **bold** are required.

### Input options

| Parameter | Description | Value(s) |
|:----|:----|:----|
| **--segments** | Initial copy number calls in SEG format, as output by the copy_number_caller `tumor-normal-wgs` or `tumor-only-wgs` subcommand. | File path |
| **--log-ratios** | Log ratios file in BED format (Contig, Start, End, LogR), as output by the copy_number_caller `tumor-normal-wgs` or `tumor-only-wgs` subcommand. | File path |
| **--bafs** | Tumor BAF values in BED format (Contig, Start, End, BAF, Ref_AD, Alt_AD), as output by the copy_number_caller `tumor-normal-wgs` or `tumor-only-wgs` subcommand. Used for estimation of allele-specific copy number. | File path |
| **--reference** | Path to the input reference FASTA file. The FASTA file must be indexed with a .fai file. | File path |
| --tumor-only | Include when the input files were generated by `tumor-only-wgs`. Enables germline/somatic segment classification and marks germline segments with the `GERMLINE` INFO field in the output VCF. | Flag |

### Output options

| Parameter | Description | Value(s) |
|:----|:----|:----|
| --output-dir | Path to output directory. | Directory path [default: .] |
| --output-prefix | Prefix prepended to all output filenames (for example a sample ID), joined with an underscore. If unset, default filenames are used. | Text [default: none] |
| --overwrite | Overwrite output files if they already exist. By default, the command exits with an error if an output file already exists. | Flag |

### Sample metadata options

| Parameter | Description | Value(s) |
|:----|:----|:----|
| **--tumor-purity** | Tumor purity. Use if the tumor purity of the sample is known prior to the analysis. Requires: --tumor-ploidy. | Float; Range: [0.15 - 1] |
| **--tumor-ploidy** | Tumor ploidy. Use if the tumor ploidy of the sample is known prior to the analysis. Requires: --tumor-purity. | Float:positive |
| **--sex** | Sex of sample. An `unknown` value excludes allosome segments from copy-number calling. | Enum: {male, female, unknown} |
